# AI Landing Page

A simple and responsive AI Landing Page created using HTML and CSS.

## 📌 Project Description

This project is a beginner-friendly landing page developed as part of frontend practice. It demonstrates the fundamentals of HTML and CSS by creating a modern AI company website.

## ✨ Features

- Responsive Layout
- Navigation Bar
- Hero Section
- About Section
- Services Section
- Features Section
- Statistics Section
- Contact Section
- Footer
- Hover Effects
- Background Image
- Responsive Design

## 🛠 Technologies Used

- HTML5
- CSS3
