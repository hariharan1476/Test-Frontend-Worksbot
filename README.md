# Skill UI - Static Landing Page

## Project Overview

Skill UI is a simple and responsive static landing page created using only HTML and CSS. This project demonstrates basic frontend concepts such as Flexbox, hover effects, responsive design, floating navigation, and CSS animations.

## Features

- Responsive Design
- Sticky Navigation Bar
- Hover Effects
- Animated Cards
- Floating Side Menu
- Tooltip Effect
- Font Awesome Icons
- Mobile Friendly
- Beginner Friendly Code

## Technologies Used

- HTML5
- CSS3
- Font Awesome Icons

## CSS Concepts Used

- Universal Selector

- Border Radius
- Box Shadow
- Media Queries

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.

No installation is required.
